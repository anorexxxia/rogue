# Roguelike

Консольная roguelike-игра на Python в духе классической игры Rogue (1980). Игрок исследует процедурно генерируемые подземелья, сражается с противниками и взаимодействует с предметами.

Проект выполнен в рамках командного PET-проекта.

## Возможности

- Процедурная генерация уровней, комнат и коридоров.
- Перемещение персонажа по игровому миру и исследование подземелья.
- Пошаговые сражения с противниками.
- Система характеристик персонажа и предметов.
- Работа с оружием, расходуемыми предметами и эффектами.
- Сохранение и восстановление игрового состояния.
- Отображение игрового мира в терминале с помощью `curses`.

## Технологии

- **Python**
- **ООП**
- **curses** — отображение игры в терминале
- **JSON** — сохранение и загрузка данных

## Запуск

Для запуска требуется установленный Python 3.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/anorexxxia/rogue.git
   cd rogue
   ```

2. Запустите игру:

   ```bash
   python3 main.py
   ```

Для работы `curses` рекомендуется использовать Linux или macOS с поддержкой терминала. В Windows может потребоваться дополнительная настройка.

## Структура проекта

- `domain/` — игровая логика: персонаж, противники, боевая система, предметы и генерация уровней.
- `datalayer/` — работа с сохранениями и данными в JSON.
- `presentation/` — отображение игрового мира и взаимодействие с терминалом.
- `main.py` — точка входа в приложение.
